# 评教自动答题器（Edge 扩展）

无需安装 Python、无需配置环境。直接加载到 Edge 浏览器即可使用。

## 安装步骤（一次性）

1. 打开 Edge 浏览器，地址栏输入 `edge://extensions` 并回车
2. 打开页面右上角的「**开发人员模式**」开关
3. 点击「**加载解压的扩展程序**」，选择本文件夹「**评教扩展**」
4. 加载成功后，工具栏会出现扩展图标

> 注意：文件夹位置不要移动或删除，否则扩展会失效。

## 使用方法

1. 打开评教系统并登录，进入「**按任务评教**」名单页
2. 两种方式启动：
   - 点击 Edge 工具栏的**扩展图标**，在弹出的面板里点「**开始**」
   - 或直接点页面右下角的「**开始自动评教**」浮动按钮
3. 程序会自动遍历所有未评老师：
   - 进入问卷 → 自动填答案 → 提交 → 返回名单页 → 下一个
   - 遇到服务器 500 失败时，自动点「取消」返回、等待几秒重试，直到成功
4. 全部完成后，页面会提示「全部完成」

## 修改答案

- 点扩展图标 → 展开「答案配置」→ 可修改每题答案（JSON 格式）和第 13 题文本 → 点「保存答案」
- 默认答案：Q1 支持理论课/实践课两套，Q2–Q12 固定，Q13 填「无」

## 文件说明

- `manifest.json` — 扩展配置
- `content.js` — 核心逻辑（遍历、答题、提交、500 重试）
- `popup.html` / `popup.js` / `popup.css` — 扩展图标面板（开始/停止、进度、日志、答案配置）
- `icon.png` — 扩展图标

## 常见问题

- **扩展图标不显示**：确认在 `edge://extensions` 里已开启，且没有报错。
- **点击开始没反应**：确认当前页面是评教「名单页」，且已登录。
- **报错请提供日志**：点扩展图标，把「运行日志」里的内容复制给开发者。
